Суть первого предупреждения. Атрибут version в файле Compose устарел. В Docker Compose v2 схема файла Compose определяется автоматически, и явное указание version: "3" больше не требуется, оно игнорируется. Предупреждение носит информационный характер и рекомендует удалить строку version из docker-compose.yaml, чтобы избежать путаницы. 

Суть второго предупреждения. Docker Compose обнаружил «осиротевший» контейнер task5-portainer-1. Это произошло потому, что после удаления compose.yaml сервис portainer перестал быть описан в файлах Compose текущего проекта, а контейнер, созданный ранее для этого сервиса, остался запущенным. Compose классифицирует его как orphan (сироту), поскольку он принадлежит проекту task5, но не соответствует ни одному сервису в актуальной конфигурации.
